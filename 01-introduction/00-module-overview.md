# Module 01 — Introduction to Java

## Module Goal

By the end of this module, you will understand **what Java is, why it was created, and how it fundamentally executes your code** — before you write a single line of "real" Java logic. Every later module builds on this mental model. Skipping it is the #1 reason people memorize Java syntax without ever understanding *why* the language behaves the way it does.

## Topics Covered in This Module

1. **[What Is Java?](01-what-is-java.md)** — Definition, core identity, what kind of language Java is (compiled, statically typed, object-oriented, garbage-collected).
2. **[History of Java](02-history-of-java.md)** — Where Java came from (the Green Project), why it looks the way it does, and the version timeline through Java 25.
3. **[Features of Java](03-features-of-java.md)** — The defining characteristics (platform independence, robustness, security, multithreading, etc.) and *why* each was a deliberate design decision, not an accident.
4. **[JDK vs JRE vs JVM](04-jdk-vs-jre-vs-jvm.md)** — The most commonly confused (and most commonly interview-asked) trio of terms, explained with diagrams.
5. **[How Java Works Internally](05-how-java-works.md)** — The full journey from `.java` source file to a running program: compilation, bytecode, class loading, interpretation, and JIT compilation.
6. **[Setting Up Java](06-setting-up-java.md)** — Installing a JDK, verifying your setup, understanding `PATH` and `JAVA_HOME`, and choosing a JDK distribution.
7. **[Your First Java Program](07-first-java-program.md)** — `HelloWorld.java` dissected keyword-by-keyword, plus common beginner mistakes.
8. **[Java Editions & Version Timeline](08-java-editions-and-versions.md)** — Java SE vs EE vs ME, the LTS release model, and what changed in each major version through Java 25.
9. **[Module Summary, Interview Questions & Exercises](09-module-summary-exercises.md)** — Consolidated recap, quiz, and practice problems.

## Prerequisites

- General programming literacy: you should already understand what a variable, a loop, a function, and a program's execution flow are — in *any* language (Python, C, JavaScript, etc.)
- No prior Java experience required.
- No specific software required yet — installation is covered in this module.

## How to Study This Module

Read in order. Topics 1–3 build your conceptual model (what and why). Topic 4 clears up terminology. Topic 5 is the deepest and most important — read it twice if needed, it's the foundation for JVM Internals (Module 16) and Performance (Module 22) later. Topics 6–7 get your hands dirty. Topic 8 gives you the historical map so version numbers you'll see throughout the rest of the course ("added in Java 8," "since Java 17") make sense.
